# Project Direction

## Current Hardware
- RP2040 development board
- ILI9341 TFT display
- Standard RGB LEDs
- Handwired / prototype wiring

---

## Planned Hardware Evolution
- Handwired build electronics → full PCB
- RP2040 Dev Board → ESP-32 Wroom-1 Dev Board → ESP-32 Wroom-1 N8R8 Module 
- Standard RGB LEDs → Addressable RGB LEDs
- Handwired prototype → Custom PCB
- USB → Native USB-C implementation

---

## Planned Software Changes
- Basic TFT menus → More advanced UI system
- Simple communication → PC companion application
- Static visuals → Album art + app icon support

---

## Long-Term Ideas
- Wireless support
- Bluetooth functionality
- Improved animations
- Standalone functionality
- More polished enclosure
