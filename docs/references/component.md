# Components

### Reference sheet showing all electronic components used in the latest stable release, along with purchase links and component history across hardware revisions.

> [!NOTE]
> This document acts as a reference sheet for all electronic components used in the latest stable hardware release, along with links to the parts used during development.
>
> It also includes the history of component additions, removals, and replacements across each hardware prototype revision.
>
> Currently, this document reflects the components used in [Electronics Prototype 0.3](/hardware/Electronics/Prototype%201.5).

> [!TIP]
> Components where the **Link** column is marked as `Any` are considered generic enough that they can typically be purchased from any vendor without causing compatibility issues.
